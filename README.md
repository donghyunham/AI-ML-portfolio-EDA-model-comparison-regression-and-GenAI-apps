# AI & Machine Learning Project Portfolio

## Profile & Tech Stack

* **Core & Data Science:** Python, Pandas, NumPy, Matplotlib, Seaborn
* **Machine Learning:** Scikit-learn (Classification, Regression, Pipeline, Evaluation Metrics)
* **Generative AI & LLM:** AWS Bedrock, AWS PartyRock, Prompt Engineering (Agentic Workflow, Task Decomposition)
* **Tools & Environment:** VS Code, Jupyter Notebook, Git, GitHub
