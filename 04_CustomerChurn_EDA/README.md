# Customer Churn 모델 비교 프로젝트

## 1. 프로젝트 개요
본 프로젝트는 Customer Churn 데이터를 활용하여 여러 머신러닝 분류 모델을 비교·분석하는 것을 목표로 한다.

단순히 정확도가 높은 모델을 찾는 것이 아니라, 각 모델의 특성과 장단점을 이해하고 실제 비즈니스 상황에서 어떤 모델이 더 적합한지 판단하는 데 중점을 둔다.

---

## 2. 문제 정의
고객 이탈(Churn)은 기업의 수익성과 직결되는 중요한 문제이다. 본 프로젝트에서는 고객의 사용 패턴 및 계약 정보를 기반으로 이탈 가능성이 높은 고객을 예측하는 모델을 구축한다.

---

## 3. 데이터 설명
- 데이터 파일: `churn.csv`
- 타겟 변수: `Churn` (1: 이탈, 0: 유지)
- 수치형 변수와 범주형 변수가 혼합된 전형적인 고객 데이터

---

## 4. 전처리 전략
- 결측치 처리
- 범주형 변수 One-Hot Encoding
- 수치형 변수 스케일링
- 학습 데이터 / 테스트 데이터 분리

모든 모델에 동일한 전처리 방식을 적용하여 모델 구조에 따른 성능 차이를 비교할 수 있도록 구성하였다.

---

## 5. 사용 모델
본 프로젝트에서 비교한 모델은 다음과 같다.

- Logistic Regression
- Random Forest
- Support Vector Machine (SVM)
- Gradient Boosting

---

## 6. 평가 지표
모델 성능 평가는 다음 지표를 기준으로 수행하였다.

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

---

## 7. 결과 요약 및 인사이트
- 트리 기반 모델은 비선형 관계를 잘 학습하여 높은 성능을 보였다.
- Logistic Regression은 해석 가능성이 높아 베이스라인 모델로 적합하다.
- 단일 지표보다는 여러 지표를 종합적으로 고려하는 것이 중요하다.

---

## 8. 한계 및 개선 방향
- 클래스 불균형 문제에 대한 추가적인 고려 필요
- 하이퍼파라미터 튜닝을 통한 성능 개선 가능
- Feature Importance 및 SHAP 분석을 통한 해석 강화 가능
