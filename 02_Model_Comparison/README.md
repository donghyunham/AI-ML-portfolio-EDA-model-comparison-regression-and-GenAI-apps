# 02. Model Comparison - Multi-Classifier Performance

본 프로젝트는 Iris 데이터셋을 기반으로 다양한 머신러닝 분류 알고리즘의 성능을 비교 분석한 프로젝트입니다.

## 1. 개요
- **데이터셋**: Iris Dataset (`load_iris`, 150개 샘플)
- **실행 파일**: `model_comparison.ipynb`

## 2. 적용 모델 및 평가 결과
- **평가 지표**: Accuracy Score
- **모델별 정확도**:
  - `Logistic Regression`: 1.00
  - `Decision Tree Classifier`: 1.00
  - `Random Forest Classifier`: 1.00

## 3. 시각화
- Seaborn `barplot`을 활용하여 각 모델의 정확도 성과를 직관적 비교 차트로 출력
