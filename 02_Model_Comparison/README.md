# 02. Model Comparison - Multi-Classifier Performance

본 프로젝트는 동일한 머신러닝 데이터셋에 대해 여러 분류(Classification) 알고리즘을 적용하고 성과를 비교 평가하는 프로젝트입니다.

## 사용 데이터셋 및 모델
- **데이터셋**: Iris Dataset (`load_iris`)
- **비교 모델**:
  1. Logistic Regression
  2. Decision Tree Classifier
  3. Random Forest Classifier

## 주요 평가 지표 및 시각화
- **평가 지표**: Accuracy Score
- **시각화**: Seaborn 막대그래프(`barplot`)를 활용한 모델별 정확도 비교
