# 02_Model_Comparison



## 1. 프로젝트 개요

본 프로젝트는 **동일한 Customer Churn 데이터셋**과 **동일한 전처리 조건** 하에서

여러 머신러닝 모델을 비교·분석하는 것을 목표로 합니다.



단순히 정확도(Accuracy)만 비교하는 것이 아니라,

- 각 모델의 **성능 차이**

- **과적합 여부**

- **해석 가능성**

- 실무 적용 관점에서의 **장단점**



을 함께 분석합니다.



---



## 2. 사용 데이터셋

- 데이터: Customer Churn Dataset

- 타겟 변수: `Churn` (이탈 여부)

- 특징:

- 수치형 + 범주형 변수가 혼합된 전형적인 비즈니스 데이터

- 클래스 불균형이 존재함



---



## 3. 전처리 요약

- 결측치 처리

- 범주형 변수 인코딩 (One-Hot Encoding)

- 수치형 변수 스케일링

- 학습/검증 데이터 분리 (Train/Test Split)



※ 전처리 과정은 모든 모델에 **동일하게 적용**함



---



## 4. 비교 모델

본 프로젝트에서 비교한 모델은 다음과 같습니다.



- Logistic Regression

- Random Forest

- Gradient Boosting

- Support Vector Machine (SVM)



---



## 5. 평가 지표

모델 성능 평가는 아래 지표를 기준으로 수행했습니다.



- Accuracy

- Precision

- Recall

- F1-score

- ROC-AUC



---



## 6. 모델 비교 결과 요약

- 단순 정확도 기준으로는 트리 기반 모델이 우수한 성능을 보였음

- Logistic Regression은 해석 가능성이 뛰어나 베이스라인 모델로 적합

- 복잡한 모델일수록 과적합 가능성이 존재함



---



## 7. 결론 및 인사이트

- **모델 선택은 성능뿐 아니라 해석 가능성과 운영 환경을 함께 고려해야 함**

- 비즈니스 맥락에서는 단일 지표보다 **종합적인 판단**이 중요함

- Customer Churn 문제는 모델 성능 외에도 **피처 설계**가 매우 중요함
